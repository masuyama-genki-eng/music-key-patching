\title{Does a Music Transformer Know What Key It Is In?\\
Causal Interventions on an Emergent Tonal Representation}

% アブストラクト。主張を先に置き，証拠を順に並べる。
% 「読めること」と「使っていること」は別 → 使用を直接テストする → held-out で確認
% → 生成音のフィードバック以前に効く → 機構 → 公開モデルで再現。
\begin{abstract}
We can decode musical attributes from the activations of a music generation
model, but decoding does not show that the model uses what we decode. We test
use directly. We train Transformers on symbolic music whose vocabulary contains
only absolute pitch and time, and we replace the low-dimensional key component
of the hidden state with the component of a different key while we keep the
musical prompt fixed. On a held-out test set, with the layer, the subspace, the
metrics and the statistical tests all fixed in advance, the edit moves
generation to the injected key, and a rank-matched random edit does not
(\TBD{held-out sweep running}). The effect appears before any generated note can
feed back: without sampling a single new token, the edit shifts the next-pitch
distribution toward the injected key ($+0.26$ probability mass, against $+0.02$
for the random control, in $12/12$ keys after Holm correction). We also find two
dissociations. The key is decodable across many layers, but the edit changes the
output only in a narrow middle band, and an edit restricted to pitch positions
does nothing at all. The effect is therefore not a direct write to pitch
decisions, and linear decodability is a weak guide to causal use. Finally, both
the probe and the edit transfer to a public model trained on real music
($7.8\times$ the matched control, $12/12$ keys). We conclude that a music
Transformer computes a manipulable key representation and consults it during
generation.
\end{abstract}

\begin{keywords}
music generation, interpretability, causal intervention, tonality, probing
\end{keywords}

\section{Introduction}
\label{sec:intro}

% 背景。音楽生成モデルは調性のある音楽を書く。既存研究は「調が読める」ことを示したが，
% 読めることは使っていることを意味しない。
Music generation models write convincingly tonal
pieces~\cite{hadjeres2017deepbach,huang2019musictransformer,copet2023musicgen}.
They settle into a home key, move away from it, and return. Recent work shows
that we can read musical attributes, including key, out of the activations of
such models with trained classifiers~\cite{syntheory2024}. Reading an attribute,
however, does not show that the model uses it. A signal can be decodable from a
representation while the model ignores it when it
acts~\cite{hewitt2019control,belinkov2022probing}. Nobody has yet tested whether
a music model uses an internal key representation when it generates.

% 他分野では因果テストが確立している。Othello-GPT が代表例。
Other domains already apply the causal test. A model trained only to predict
Othello moves builds an internal board, and editing that board changes which
moves the model treats as legal~\cite{li2023othello,nanda2023emergent}.
Researchers have applied the same standard to chess, mazes, and reinforcement
learning environments~\cite{karvonen2024chess,maze2024,iris2026}.

% 音楽側には probe と steering があるが，steering は「方向が効く」ことしか示さない。
Music has probes, and it has steering. Steering methods adapt inference-time
interventions from language models~\cite{li2023iti,zou2023repe} and push an
attribute along a learned direction~\cite{smitin2024,musicrfm2026}. Such a
result shows that a direction influences an attribute. It does not show that the
model holds a representation whose \emph{value} we can set: remove the current
value, install a different one, and observe the model act on the new value.

% 近年の研究では，言語モデルにおける方向探索手法が直接比較されている。
% Wu らは AxBench を提案し，difference-of-means，線形プローブ，SAE を比較した。
% Arad らは SAE ステアリングが特徴選択に強く依存することを示した。
% これらは「属性に対応する方向が，その属性を最も効果的に制御する方向とは限らない」
% ことを示唆する。本研究の probe と因果効果の乖離に直接つながる。
Recent studies have directly compared direction-finding methods in language
models. Wu et al.~\cite{wu2025axbench} introduced AxBench and compared several
methods, including difference-of-means, linear probes, and sparse autoencoders
(SAEs). Their results showed that simple baselines such as difference-of-means
often achieved stronger steering performance than SAE-based methods. Arad et
al.~\cite{arad2025selecting} further showed that the performance of SAE-based
steering strongly depends on how one selects SAE features, and that selecting
features by their measured effect on model outputs can outperform selection
based only on activation statistics. These findings suggest that a direction
associated with a target attribute is not necessarily the direction that most
effectively controls that attribute. We extend this observation from language to
music, and from feature selection to network depth and token position.

% 提案。musical key を状態変数に選ぶ理由を3つ挙げる。
We run the causal test with musical key as the state variable. We choose key for
three reasons. First, theory and psychological measurement define key outside the
model~\cite{krumhansl1982}, so the state we probe does not depend on our own
labeling. Second, the model must compute key by integrating pitch evidence over
time, because the vocabulary names no key. Third, the scale of a key gives us an
objective success measure, so we do not need a learned judge. We replace the key
component of one layer's activations with the component of a donor key, and we
ask what the model composes next. We fix every analysis choice before we look at
the confirmatory data, we add a logit-level test that removes feedback from
generated notes, and we add token-type ablations that rule out a direct write to
pitch decisions. We release the testbed, which contains a leak-free tokenizer, a
corpus with exact per-token key labels, and the frozen protocols.

\section{Method}
\label{sec:method}

\subsection{Data, models, and protocol}
% データ。真の調ラベルが全音符に必要なので合成する。語彙に調は入らない。
We need the true key at every note, so we generate the training data.
\textbf{D-SYN} comes from a functional-harmony state machine that voices each
chord for four parts and optionally adds a melody. It writes $200$k/$10$k/$10$k
train/validation/test pieces of $278$--$508$ tokens, and each piece contains
$0$--$3$ modulations. The machine knows the key it writes in, so every token
carries a true key label $\kappa(t)$ over $24$ classes. \textbf{We never give
these labels to the model}: they train and score the probe only. The vocabulary
holds $124$ types---\texttt{BAR}, \texttt{POS}, absolute-MIDI \texttt{PITCH},
\texttt{DUR}, and structural symbols---and a unit test enforces the absence of
key, chord, and degree tokens.

% モデル。M-CTRL を6本，M-REF は審査専用。品質ゲートは事前設定。
\textbf{M-CTRL} is a GPT-2 style
decoder~\cite{vaswani2017attention,radford2019gpt2} with $8$ layers, $d{=}512$,
and about $25$M parameters. We train it with and without transposition
augmentation, with three seeds each, which gives six models. \textbf{M-REF}
shares the architecture but uses a different seed and a disjoint slice of the
data. We never probe or edit M-REF; it only judges whether edited music still
sounds like music, so no model grades its own work. All six models clear a
quality gate that we set in advance: validation next-token top-$1$ of
$0.878$--$0.881$, against $0.434$ for a predictor that always emits the most
frequent token. We fixed all decision rules, thresholds, and controls before we
ran the experiments, we log every deviation, and we report negative results.

\subsection{Probing with controls}
% probe と C1--C3 統制。C3 は入力表層ベースライン。
We train linear probes~\cite{alain2017probes,belinkov2022probing} that map the
residual stream $h_\ell(t)$ to $\kappa(t)$, and we split train and test by
piece. We bound the probes with three control families. \textbf{C1} permutes the
key labels within each piece; the score of that probe on the true keys gives the
\emph{selectivity floor}~\cite{hewitt2019control}, which we subtract from every
margin we report. \textbf{C2} is an untrained model. \textbf{C3} names the key
from the notes alone: logistic regression on a pitch-class histogram, and
Krumhansl--Schmuckler (KS) template
matching~\cite{krumhansl1990,temperley1999ks}, over windows
$W\in\{8,\dots,64\}$. Section~\ref{sec:h1} extends C3 to the full prefix. Our
frozen rule \textbf{DR-H1} requires the selectivity-corrected probe $F_1$ to beat
the best C3 baseline with a piece-level BCa~\cite{efron1987bca} $95\%$ confidence
interval that excludes zero.

\subsection{Intervention}
\label{sec:methodB}
% 介入。式と統制。K1 の norm 逸脱も明記する。
We prompt the model with $8$ bars in a stable key. From bar~$9$ on, we edit one
layer's activations at every generated position, following the activation
patching literature~\cite{geiger2021causal,meng2022rome}:
\begin{equation}
h \;\leftarrow\; h - P_V h + P_V\,\mu_{\kappa^{*}},
\label{eq:edit}
\end{equation}
where $V$ is an orthonormal key subspace, $P_V{=}VV^{\!\top}$ projects onto it,
and $\mu_{\kappa^{*}}$ is the mean activation of the donor key $\kappa^{*}$.
\textbf{We never change the prompt.} We build $V$ in three ways: the probe row
space (\textbf{V-PROBE}), the span of the per-key means (\textbf{V-MEAN}), and an
optimized subspace trained by distributed alignment search
(\textbf{V-DAS})~\cite{geiger2024das}.

% 統制。K1 の rank/norm 逸脱を正直に述べ，K1-norm を追加する。
Four controls bound the result. \textbf{K1} uses a random subspace of the same
rank and shape. Our pre-registration also asked K1 to match the perturbation
\emph{magnitude} of the edit; the implementation matches rank only, so we log the
deviation instead of hiding it. We measure $\|\Delta\|=34.6$ for the edit against
$24.1$ for K1, a ratio of $1.44$, on activations of norm about $169$. We
therefore add \textbf{K1$^{\mathrm{norm}}$}, which uses the same random subspace
but rescales the perturbation to the magnitude of the edit, so that we control
magnitude exactly. \textbf{K2} is a sham edit that must reproduce the clean
output token by token, and it does ($100/100$ on the selection prompts).
\textbf{K3} borrows the subspace of another layer. \textbf{K4} transposes the
prompt itself and gives the behavioral ceiling.

% 評価指標とガード。
We score continuations with two measures. The \emph{target-key rate} ($\tkr$) is
the fraction of continuations whose KS estimate equals the injected key, and we
report it strictly. The \emph{in-key rate} ($\ikr$) is the fraction of
continuation pitches that belong to a given scale, and it needs no estimator. We
also cap the damage an edit may do. Before we ran a single edit, we measured how
far the perplexity of M-REF rises across $7{,}989$ \emph{natural} modulations in
the validation data, and we froze the $90$th percentile of that rise as our
musicality budget, $\ppl{=}0.613$. We call a $\tkr$ scored under this budget
\emph{guarded}, and every headline number below is guarded.

\subsection{Selection phase and confirmatory phase}
\label{sec:confirm}
% 設計上の最重要点。旧掃引は「選択」であって「確認」ではない，と自ら明言する。
Our first sweep compared $8$ layers and $3$ subspace families on $100$ prompts,
and it evaluated the best cell (V-PROBE at L$4$) on those same prompts. Those
prompts also lie inside the pool that trained the probe. Holm correction covered
the $12$ target keys, but it did not cover the selection of the layer and the
subspace. We therefore treat that sweep as a \emph{selection} phase, and we add a
\emph{confirmatory} phase. We draw $100$ fresh prompts from a region of the test
split that neither probe training nor any earlier run has touched. We fix the
layer, the subspace, the timing, the targets, the controls, the guard, the
metrics, the tests, the seeds, and the sample size in a version-controlled
document, and we commit that document before the first confirmatory number
exists. We repeat no layer or subspace search. We exclude identity cells, in
which the injected key equals the key of the prompt, from the primary analysis,
and we report them separately as a sanity check. \textbf{We froze all
intervention choices and evaluation criteria before we evaluated the held-out
set.}

\section{Results}
\label{sec:results}

\subsection{The model computes the key instead of copying it from the surface}
\label{sec:h1}
% H1。probe が入力表層ベースラインを上回る。
At L$4$ the probe reaches macro-$F_1$ $0.927$, the best pre-registered input
baseline reaches $0.790$, and the selectivity floor is $0.032$, so the corrected
margin is $+0.105$ (BCa $95\%$ CI $[0.091,0.114]$). This margin excludes zero in
layers $1$--$7$ of all six trained models, and DR-H1 holds in $6/6$. It turns
negative only at the raw embedding ($-0.20$), where the input surface should
indeed win. An untrained model scores $0.243$, so the architecture alone does not
supply the key.

% 履歴長の交絡。probe は全履歴を見るのに C3 は W<=64 だった。拡張しても結論は変わらない。
The probe attends the full prefix, while C3 saw at most $64$ tokens, so a reader
may ask whether history length alone explains the margin. We therefore extended
C3 to the full prefix and added two stronger variants: histograms with
exponential recency decay, and a concatenation of a short and a long window. The
window curve turns over inside the extension, at $W{=}96$ ($0.801$), and falls to
$0.752$ at $W{=}512$, because evidence from before a modulation poisons a
histogram that cannot down-weight it. Against the strongest variant ($0.824$) the
margin stays positive at $+0.071$ $[0.056,0.081]$, and all twelve size-and-seed
verdicts stay unchanged. We therefore claim that the internal representation
makes key more linearly accessible than these pitch-statistical baselines. We do
not claim that it exceeds every possible function of the input, because the
hidden state is itself a function of the input.

\subsection{Editing the key representation changes the composed key}
\label{sec:h3}
% 選択フェーズの結果。正直に「選択」と呼ぶ。
\textbf{Selection phase.} V-PROBE at L$4$ gave the best in-budget cell, with a
guarded strict $\tkr$ of $0.378$ against $0.075$ for its layer-matched K1, a
ratio of $5.0$. All $12$ targets separated after Holm correction ($p<10^{-4}$),
$87\%$ of edits stayed in budget, and the edit reached $58\%$ of the K4 ceiling.
Pitch content agrees without the estimator: $\ikr$ is $0.937$ for the injected
key and $0.646$ for the key of the prompt. The optimized subspace scored lower
than the probe row space (V-DAS, $0.213$), which matches the observation of Wu et
al.~\cite{wu2025axbench} that a simple representation-based direction can
outperform an optimized one. V-MEAN edits destroy the music at deep layers, where
at most $5\%$ stay in budget.

% 確認フェーズ。結果待ち。
\textbf{Confirmatory phase.} \TBD{held-out confirmatory sweep executing:
per-target guarded $\tkr$, K1, K1$^{\mathrm{norm}}$, rank-biserial $r$,
Holm-corrected $p$, BCa CI, guard rate, and the identity sanity check land here}.

% 特異性。狙った調に入る，という主張。
\textbf{Specificity.} The edit does not merely leave the source key; it lands on
the key we inject. \TBD{confirmatory specificity: diagonal mass, fifth-neighbor
mass, source retention, edit \vs K1}. In the selection data, success falls gently
as the target moves away around the circle of fifths, from $0.395$ at one step to
$0.280$ at the tritone, which is how moving a key should behave.

\subsection{The edit acts before the model hears a single new note}
\label{sec:nextpitch}
% 最重要の追加実験。フィードバック説明を論理的に排除する。
A sustained edit leaves one alternative explanation: the edit may perturb the
first few notes, and the model may then re-estimate the key from its own output.
We remove that explanation at the logit level. We extend each held-out prompt
with a teacher-forced, key-neutral structural prefix (\texttt{BAR},
\texttt{POS\_1}), we apply the edit from the bar-$9$ boundary, and \emph{we never
sample a token}. We then read the next-token distribution over pitch tokens and
score two frozen measures: $P_{\mathrm{target}}$, the probability mass on pitches
diatonic to the injected key, and
$\Delta_{\mathrm{key}}=\log P_{\mathrm{target}}-\log P_{\mathrm{source}}$.

% 数値。
The edit raises $\Delta_{\mathrm{key}}$ by $0.695$ over the clean run, while the
matched random edit raises it by $0.041$. The mass on the target scale rises by
$0.255$ from a clean baseline of $0.547$, against $0.017$ for the control. The
separation holds in $12/12$ keys after Holm correction, with a worst-case
$p=5\times10^{-16}$ and rank-biserial $r\ge0.99$. \textbf{The edit therefore
changes the next musical decision of the model before any generated note can feed
back.}

\subsection{Where we can read the key is not where the model uses it}
\label{sec:h5}
% 二重の乖離。層とトークン型。
Two dissociations locate the effect. \emph{Across layers}, the probe saturates
over a broad band (macro-$F_1$ $0.920$--$0.929$ for L$2$--L$6$), but when we edit
each layer in turn and subtract the matched control we obtain a single
mid-network peak: $0.03$, $0.04$, $0.19$, $0.26$, $\mathbf{0.30}$, $0.26$,
$0.23$, $0.23$ for L$0$--L$7$, and the best-against-median CI $[0.038,0.109]$
excludes zero. The edit does almost nothing at L$0$--L$1$, where the probe
already reads the key well (Fig.~\ref{fig:layers}). We claim middle-layer
concentration rather than a landmark layer, because the second seed reproduces
every verdict with its peak at L$2$.

% トークン型。PITCH のみは無効，BAR/DUR が効果の大半。
\emph{Across token types}, we restrict the write by token type. An edit at
\texttt{PITCH} positions alone does nothing (guarded $\tkr$ $0.077$, at the K1
floor) and leaves the music intact, while an edit at \texttt{BAR} and
\texttt{DUR} positions alone carries $69\%$ of the full effect. No restriction
improves the guard rate. \TBD{confirmatory token-type arms land here}. An
intervention that simply steered pitch logits would show the opposite pattern.
Together with the layer result, this shows that linear decodability is a weak
guide to causal use, which parallels the feature-selection result of Arad et
al.~\cite{arad2025selecting} in language models.

\subsection{The result transfers to a public model trained on real music}
\label{sec:wild}
% 外部検証。公開モデルと実音楽。
We probe and edit the Anticipatory Music
Transformer~\cite{thickstun2023anticipatory}, which its authors trained on Lakh
MIDI~\cite{raffel2016lakh}, MetaMIDI~\cite{ens2021metamidi}, and
FMA~\cite{defferrard2017fma}. We evaluate it on $300$ Bach
chorales~\cite{hadjeres2017deepbach,huang2017coconet} with human local-key
labels~\cite{gotham2023wheninrome}. Here we read the probe at the positions where
the model is about to choose a pitch, because the (time, duration, note) encoding
forces that convention; the supplementary shows that the verdict inverts if we
read after the note instead. The probe beats the surface baselines with a
corrected margin of $+0.196$ $[0.132,0.260]$, while our own model of the same
shape does not ($+0.034$, CI crosses zero). The two setups produce C3 baselines
within $0.003$ of each other, which confirms that we matched them. We note that
this comparison varies the training data together with the tokenizer and the
training procedure, so it isolates the real-music training pipeline rather than
the data alone.

% 介入も転移する。
The intervention also transfers. We re-froze the budget from natural modulations
in the chorales and used a \emph{different} public checkpoint as the judge. The
edit then reaches $7.8\times$ the matched control (guarded $\tkr$ $0.479$ against
$0.061$), separates in $12/12$ targets, keeps $99.7\%$ of continuations in
budget, and moves pitch content across ($\ikr$ $0.890$ for the injected key
against $0.753$ for the prompt's). Its causal peak (L$8$) again differs from its
probe peak (L$10$).

% 撤回。査読者が最も攻撃しやすい点を，自分で先に潰す。
One result from our first run did not survive its control, and we retract it. We
appeared to find a key prior: the model never reached F$\sharp$ major, and
success tracked how common each key is in the corpus (Spearman $+0.91$). We had
estimated the edit targets from the same imbalanced corpus, however, and
F$\sharp$ major never occurs in it, so the target for F$\sharp$ was a zero
vector. When we re-estimate the subspace and the targets from a key-balanced
corpus, F$\sharp$ rises to $0.617$ and the correlation falls to $+0.41$, which is
not significant. We report this episode because the failure mode transfers: edit
targets estimated from an imbalanced corpus can manufacture a convincing but
false model prior.

\subsection{What our results do not show}
\label{sec:limits}
% 主張の境界を3つ，測定値つきで述べる。
We bound three further claims with measurements. \emph{Capacity}: next-token
accuracy stays flat from $0.5$M to $86$M parameters, yet the smallest model has
no decodable key state and $90\%$ of its edits leave the budget, and
manipulability peaks near $26$M. \emph{Persistence}: after a one-shot
installation the pitch content stays shifted for many bars, but splicing the
tokens of that one bar reproduces the entire effect, so the model re-estimates
the key from evidence at every step and does not hold a latent memory that is
independent of the emitted notes. \emph{Geometry}: the twelve tonic directions
arrange themselves on a circle of fifths, and transposition acts as an
approximately linear map, but the twelve maps do not form a cyclic group, so our
pre-registered H2b does not hold. The supplementary reports all three in full.

\section{Discussion and Limitations}
\label{sec:disc}
% 主張を一文で述べ直し，解釈語 (world model) は解釈として扱う。
Our evidence supports a precise claim: within this training condition, the model
computes an internal representation of musical key and consults it during
generation. The representation is manipulable, it is specific to the injected
key, it acts before feedback, and it concentrates in middle layers and at
structural token positions. Readers may call such a representation a world model;
we use that term only as an interpretation, not as a result.

% ギャップも情報である。
The gaps inform us as well. The edit reaches only $58\%$ of the behavioral
ceiling, it fails exactly where the state is most readable (L$0$--L$1$ and
\texttt{PITCH} positions), and K3 shows that the middle layers share one subspace
rather than relearning it at each depth.

% 限界。
\emph{Limitations.} We inject major keys only; we pre-registered minor as a
secondary condition and have not run it. The KS estimator confuses keys a fifth
apart, and $\ikr$ triangulates around that weakness. Our guard measures
distributional damage under a reference model, not musicality itself, and we ran
no listening test. Our public-model result covers one checkpoint at one size. The
confirmatory phase covers our own model; the public-model intervention keeps its
original design, in which we chose the layer on disjoint prompts and froze the
budget before evaluation, but did not run a second held-out round.

\section{Conclusion}
% 結論。読めること != 使っていること，を最後にもう一度置く。
A music Transformer does not merely expose correlates of key to a probe. Under a
design in which we fixed every choice before we saw the confirmatory data,
replacing a rank-$24$ component of the hidden state moves composition to the
injected key: before any generated note can feed back, specifically toward the
target, within a frozen musicality budget, across seeds, and in a public model
trained on real music. Decodability and causal use come apart across layers and
across token positions. Reading a representation therefore does not show that the
model consults it. We release the testbed, the labels, and the frozen protocols
as a benchmark.
