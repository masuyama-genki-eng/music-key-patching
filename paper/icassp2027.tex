\begin{abstract}
% 線形プロービングは，音楽生成モデルが音楽属性を符号化していることを示すが，活性から属性を読み取れることは，モデルがそれを生成に使っていることを示さない．
% そこで本研究では，Transformerに基づく記号音楽生成モデルが，内部活性に調情報を表現し，その情報を生成に利用しているかを調べる．
% 調を明示するラベルやトークンを含まない記号音楽でTransformerを学習し，線形プロービングによって調関連部分空間を求める．
% 生成中に，この部分空間における活性の成分を目標調の平均活性の成分へ置き換える．
% この置換は，新しい音符をサンプリングする前から，目標調に属する音高へ予測確率を移動させる．
% 事前に定めた基準では，majorでは続きの35.5\%，minorでは49.5\%が目標調に従うのに対し，次元と変位量を合わせたrandom-subspace replacementでは5.6\%と2.6\%にとどまる．
% 継続生成への効果は実音楽で学習された公開モデルでも確認され，3つの公開モデルではサンプリング前の予測変化も確認される．
% 調情報を容易に読み出せる場合でも，その効果の強さは層やモデルによって異なり，プローブ性能だけでは置換の効果を判断できない．
% これらの結果は，音楽Transformerが生成に影響する置き換え可能な調情報を内部に表現していることを示す．
Linear probing shows that music generation models encode musical attributes, but reading an attribute from an activation does not show that the model uses it during generation.
We therefore investigate whether Transformers for symbolic music generation represent musical key in their internal activations and use this information during generation.
We train Transformers on symbolic music without explicit key labels or tokens and use linear probing to identify a key-related subspace.
During generation, we replace the component of the activation in this subspace with that of a target-key mean activation.
The replacement shifts probability toward pitches in the target key before any new note is sampled.
Under a pre-specified criterion, 35.5\% of continuations in major and 49.5\% in minor follow the target key, against 5.6\% and 2.6\% for a random-subspace replacement matched in dimension and displacement.
Continuation effects are also observed in public models trained on real music, and a deduplicated Bach evaluation shows shifts before sampling in three public models.
The strength of these effects varies across layers and models even when key information is readily decodable.
Therefore, probe performance alone does not determine the effect of the replacement.
These results show that music Transformers represent replaceable key information that affects generation.
\end{abstract}

\begin{keywords}
music representation analysis, symbolic music generation, activation patching, linear probing, model interpretability
\end{keywords}

\section{Introduction}
% 背景
% 近年，Transformerを用いた音楽生成モデルは，長期的な構造を持つ音楽を生成できるようになっている．
% しかし，これらのモデルが音楽情報を内部でどのような形で表現し，その情報が生成中の予測に影響しているかは十分に分かっていない．
% この対応関係を明らかにすることは，音楽生成モデルの内部機構を解釈する上で重要である．
Transformer-based music generation models can generate music with long-term structure~\cite{huang2019musictransformer,thickstun2023anticipatory,dong2023mmt}.
However, it remains unclear in what form these models represent musical information internally, and whether that information affects their predictions during generation.
Clarifying this link is important for interpreting the mechanisms behind music generation.

% 現状
% 内部表現の解析には線形プロービングが，生成結果の制御にはactivation steeringが用いられている．
% Transformerでは，各層が生成途中に数値ベクトルを計算しており，本研究ではこれを内部活性と呼ぶ．
% 線形プローブは，内部活性から属性を予測する分類器を学習し，その予測性能から属性に関する情報をどの程度読み取れるかを調べる．
% 音楽生成モデルについても，線形プロービングを用いて音楽属性を解析する研究が行われている．
% Activation steeringは，目標属性に対応する方向を内部活性に加えることで生成結果を変化させる．
% 音楽生成モデルについても，activation steeringを用いて音楽属性を制御する研究が行われている．
% このように，内部活性から音楽情報を読み取る方法と，内部活性を変更して生成結果を制御する方法の両方が研究されている．
Two tools connect internal activations, the vectors a Transformer computes at each layer during generation, to musical attributes.
A linear probe predicts an attribute from an activation, and its accuracy shows how easily the attribute can be read out~\cite{alain2017probes,belinkov2022probing}; music studies have probed musical attributes this way~\cite{syntheory2024,ma2024root,mimidi2026}.
Activation steering adds a direction associated with a target attribute to the activation to control the output~\cite{li2023iti,zou2023repe}, and has been applied to musical attributes as well~\cite{smitin2024,musicrfm2026,singh2026discovering,mimidi2026}.

% 問題
% しかし，線形プロービングとactivation steeringだけでは，内部の属性情報が実際の生成に使われているかを十分に検証できない．
% 属性を内部活性から高精度に予測できても，モデルがその情報を使って次の出力を生成しているとは限らない．
% また，activation steeringは，元の属性の情報を残したまま目標属性に対応する方向を加える．
% そのため，元の属性と目標属性の影響が混ざり，生成結果だけからそれぞれの影響を分けることは難しい．
% したがって，属性情報を内部から読み取れるかだけでなく，その情報を別の属性に対応する情報へ置き換えたときに生成結果が変化するかを検証する必要がある．
However, linear probing and activation steering alone do not fully test whether internal attribute information is actually used for generation.
A probe may accurately predict an attribute without showing that the model uses this information to generate the next output~\cite{belinkov2022probing}.
Activation steering also keeps information about the original attribute while adding a direction associated with the target attribute~\cite{li2023iti,zou2023repe}.
As a result, the effects of the original and target attributes can remain mixed, making it difficult to separate their effects from the generated output alone.
Therefore, we need to test not only whether attribute information can be read from internal activations but also whether replacing it with information for another attribute changes the generated output.

% 提案
% そこで本研究では，音楽属性の一つである調を対象とする．
% 調にはハ長調やイ短調などがあり，曲の中でどの音高が使われやすいかに関わる基本的な音楽属性である．
% 音楽生成モデルは生成中に音高を選択し，生成された音符から調を推定できる．
% そのため，調は，内部の調情報が実際の生成に使われているかを検証しやすい属性である．
% 本研究では，この調情報が生成に使われているかを検証するためにactivation patchingを用いる．
% Activation patchingとは，モデルへの入力を変えずに内部活性を置き換え，その置き換えが生成結果に与える影響を調べる方法である．
% 具体的には，現在の調に対応する成分を目標調に対応する成分へ置き換え，その置き換えによって生成音楽が目標調に従うかを調べる．

We focus on musical key as the target attribute.
Keys such as C major and A minor affect which pitches are likely to appear in a passage.
Music generation models select pitches during generation, and we can estimate the key from the generated notes.
Therefore, key is suitable for testing whether internal key information is actually used for generation.
We use activation patching to test whether the model uses this key information.
Activation patching replaces an internal activation without changing the model input and examines how this replacement affects the generated output~\cite{geiger2021causal,geiger2024das}.
Specifically, we replace the component associated with the current key with that associated with a target key and test whether this replacement makes the generated music follow the target key, as shown in Figure~\ref{fig:overview}.

% 本論文は生成手法の提案ではなく，モデル内部の分析を目的とする．
% 本研究の貢献は次の2点である．
This is an analysis, not a generation method.
We make two contributions.
\begin{itemize}
% 生成中に内部の調情報を目標調のものへ置き換えると，新しい音符をサンプリングする前から目標調に属する音高へ予測確率が移動し，生成音楽が目標調に従うことを示す．
% また，継続生成への効果は実音楽で学習された公開モデルでも確認され，AMT-12L，REMI+，MMTではサンプリング前の予測変化も確認される．
% プローブ性能だけでは介入の効果を判断できないことを示す．このpatchingの効果の強さは，調情報を容易に読み出せる場合でも，層やモデルによって異なる．
\item We show that replacing the component for the current key with that for a target key shifts probability toward pitches in the target key before any new note is sampled and makes the generated music follow the target key.
Continuation effects are also observed in public models trained on real music, and a deduplicated Bach evaluation shows shifts before sampling in AMT-12L, REMI+, and MMT.
\item We show that probe performance alone does not determine the effect of an intervention. The strength of these patching effects varies across layers and models even when key information is readily decodable.
\end{itemize}

\section{Method}
% まず線形プロービングにより，調情報を読み出せる内部表現を同定する．
% 次にactivation patchingにより，その表現を変更したときに生成音楽が変化するかを検証する．
We first use linear probing to identify internal representations from which key information can be read, and then use activation patching to test whether changing these representations affects the generated music.

\subsection{Linear Probing}
\label{sec:probe}
% プロービングのタスクを，12種類の主音と長短を組み合わせた24種類の調を予測する多クラス分類として定式化する．
% 層$\ell$のblock出力における位置$t$の内部活性を$h_\ell(t) \in \mathbb{R}^{d}$とする．これは，blockのMLP残差加算の後，layer normalizationを通す前の残差ストリームである．
% プローブは$h_\ell(t)$を入力とし，その位置にアノテーションされた調$\kappa(t)$を予測する．
% プローブは多項ロジスティック回帰であり，24種類の調に対する確率分布$p_\ell(t)$を次式で出力する．
% $W_\ell \in \mathbb{R}^{24 \times d}$と$b_\ell \in \mathbb{R}^{24}$はプローブのパラメータである．
% 学習するのはプローブのみであり，生成モデルのパラメータは固定する．
% この線形プローブにより，各Transformer blockの出力から調情報をどの程度線形に読み出せるかを定量化できる．
We formulate the probing task as 24-class key classification covering 12 tonics in major and minor modes.
Let $h_\ell(t) \in \mathbb{R}^{d}$ denote the internal activation at position $t$ at the output of block $\ell$, i.e., the residual stream after the block's MLP residual addition and before any layer normalization.
The probe takes $h_\ell(t)$ as input and predicts the annotated key $\kappa(t)$ at that position.
The probe is a multinomial logistic regression classifier that outputs a distribution $p_\ell(t)$ over the 24 keys as follows.
\begin{equation}
p_\ell(t) = \operatorname{softmax}\left( W_\ell h_\ell(t) + b_\ell \right),
\label{eq:probe}
\end{equation}
where $W_\ell \in \mathbb{R}^{24 \times d}$ and $b_\ell \in \mathbb{R}^{24}$ are the probe parameters.
We train only the probe and keep the parameters of the generation model fixed.
This linear probe allows us to quantify how linearly accessible key information is at the output of each Transformer block.

\subsection{Activation Patching}
\label{sec:patching}
% 内部活性のうち，プローブの重みベクトルが張る部分空間の成分を，目標調のものに置き換える．
% 層$\ell$では，プローブ重み$W_\ell$の行空間の正規直交基底$V_\ell$を特異値分解によって求める（ランク24）．
% $V_\ell$は正規直交であるため，$P_{V_\ell}=V_\ell V_\ell^\top$はこの部分空間への直交射影となる．
% 置き換える値は，目標調$\kappa^*$のラベルを持つ位置における$h_\ell(t)$の平均$\mu_{\ell,\kappa^*}$である．トークンタイプでは分けない．
% 8小節のプロンプトを入力し，9小節目以降のすべての続きの位置において次式の置き換えを適用する．
% これにより，線形プロービングで同定した表現をモデルが生成中に使っているかを検証できる．
We replace the component of an internal activation that lies in the subspace spanned by the probe weight vectors with the component for a target key.
For layer $\ell$, we take an orthonormal basis $V_\ell$ of the row space of $W_\ell$ in Eq.~\eqref{eq:probe} by singular value decomposition (rank 24).
Because $V_\ell$ is orthonormal,
\begin{equation}
P_{V_\ell}
=
V_\ell V_\ell^\top
\label{eq:projector}
\end{equation}
is the orthogonal projection onto this subspace.
The value we write in is the target-key mean activation $\mu_{\ell,\kappa^*}$, obtained by averaging $h_\ell(t)$ over the positions labeled with the target key $\kappa^*$, regardless of token type.
We give the model an eight-bar prompt and, at every continuation position from bar 9 onward, apply
\begin{equation}
h'_\ell(t) = h_\ell(t)
- {P_{V_\ell} h_\ell(t)}
+ {P_{V_\ell}\mu_{\ell,\kappa^*}}.
\label{eq:edit}
\end{equation}
Eq.~\eqref{eq:edit} combines linear concept erasure~\cite{ravfogel2020inlp,leace2023} with mean patching~\cite{wang2023ioi,zhang2024patching}.
This lets us test during generation whether the model uses the representation identified by linear probing.

\section{Experimental Setup}
\label{sec:setup}

\subsection{Data}
\label{sec:data}
% 主実験では，各トークンの正確な調ラベルを得るために合成音楽を用いる．
% 生成モデルの学習用に200,000曲，プロービングとパッチング用に10,000曲を生成する．
% 先頭6,000曲からプローブと目標調の平均活性を求め，評価用のpromptは残りから取る．
% 尤度閾値の較正用と参照モデルの学習用には，さらに別の楽曲を生成する（3.3節）．
% 語彙には小節，位置，絶対MIDI音高，音長を含むが，調やコードの記号は含まない．
% したがって生成モデルは調の教示を受けずに学習され，調ラベルは分析にのみ用いる．
% 実音楽にも当てはまるかを確認するため，公開チェックポイントにも同じプロービングとパッチングを適用し，人手による調ラベルを持つデータセットを用いる．
% BachではWhen in Romeの300曲のコラールを，POP909-CLでは注釈に欠損または不整合がある4曲を除いた905曲を用いる．
We use synthetic music for the main experiments to obtain exact key labels at every token.
We generate $200{,}000$ pieces to train the generation model and $10{,}000$ analysis pieces for probing and patching.
The first $6{,}000$ provide the probe and the target-key mean activations.
The evaluation prompts come from the rest.
Separate pieces are generated to calibrate the likelihood threshold and to train the reference model (Sec.~\ref{sec:eval}).
The vocabulary includes bars, positions, absolute MIDI pitches, and note lengths, but no key or chord symbols.
The generation model is therefore trained without key supervision, and key labels are used only in the analysis.
To test whether the findings extend to real music, we apply the same probing and patching to public models, using datasets with human key annotations.
We use $300$ Bach chorales from When in Rome~\cite{gotham2023wir} and $905$ of the $909$ songs in POP909-CL~\cite{pop909cl2026}, excluding four songs with missing or inconsistent annotations.

\subsection{Models}
\label{sec:models}
% 主実験には，8層，512次元の内部活性，約25Mパラメータを持つGPT-2型decoderを用いる．
% 同じアーキテクチャについて，転置augmentationの有無と3つのseedを組み合わせた計6モデルを学習し，そのうち1つを主モデルとして結果を報告する．
% 実音楽で学習されたモデルの評価には，5つの公開モデルを用いる．
% AMTでは12層，24層，36層の3つのcheckpointを用いる．
% さらに，MMTと，MMTとともに公開されたREMI baselineを用いる．
Our main model is an $8$-layer GPT-2-style~\cite{radford2019gpt2} decoder with $512$-dimensional activations and about $25$M parameters.
We train six models in total, combining two augmentation regimes with three seeds each, and report the main results on one of them.
For evaluation on real music, we use five public models.
These include $12$-, $24$-, and $36$-layer Anticipatory Music Transformer (AMT) checkpoints~\cite{thickstun2023anticipatory}.
We further use the Multitrack Music Transformer (MMT)~\cite{dong2023mmt} and the REMI+ baseline~\cite{vonrutte2023figaro} released with MMT.

\subsection{Evaluation Protocol}
\label{sec:eval}
% 評価では，二つの研究質問を検証する．
% RQ1：内部活性から，過去の音高だけでは説明できない調情報を読み出せるか？
% RQ2：内部の調関連成分を目標調のものに置き換えると，同程度のランダム部分空間の置き換えよりも，サンプリング前の次音高予測と生成された続きが目標調へ変化するか？
% 観測された効果に対する別の説明を検証するため，統制実験を行う．さらに，層とトークン位置ごとに，読み取りやすさと編集可能性を比較する．
% すべての評価基準と閾値はfinal testの前に固定する．
We structure the evaluation around two research questions.
\begin{itemize}
    \item \textbf{RQ1.} Can key information be read from internal activations beyond what can be inferred from preceding pitches?
    \item \textbf{RQ2.} Does replacing the internal key-related component with that of a target key shift both before-sampling pitch predictions and generated continuations toward the target key more than a matched random-subspace replacement?
\end{itemize}
We use control experiments to test alternative explanations of the observed effect.
We further compare readability and editability across layers and token positions.
All evaluation criteria and thresholds are fixed before the final test.

\noindent\textbf{RQ1.}
% プローブの性能は macro-F1で評価する．
% この性能が過去の音高だけで説明できるかを確認するため，それ以前の音高トークンから12種類のpitch classを数えるnote-counting baselineと比較する．
% Baselineにはロジスティック回帰とKrumhansl--Schmuckler（KS）法を用い，複数の履歴長の中で最も性能の高いものを比較対象とする．
% KS法は，12次元のpitch-class count vectorと24調それぞれのkey profileとの相関を計算し，最も相関が高い調を予測する．
% また，プローブ自体の表現力による影響を補正するため，各曲にランダムな調ラベルを割り当てたcontrol taskでも同じプローブを学習する．
% Probe marginを M_probe = (F1_probe - F1_control) - F1_noteと定義する．
% ここで，F1_probeは実際の調分類，F1_controlはランダムラベルのcontrol task，F1_noteは最も性能の高いnote-counting baselineのmacro-F1である．
% 各曲を単位としたブートストラップによる95%信頼区間の下限が0を上回る場合，probe marginは正であると判断する
We evaluate the probe using macro-$F_1$.
To test whether this performance can be explained by preceding pitches, we compare it with note-counting baselines.
The baselines count the $12$ pitch classes in preceding pitch tokens and predict the key using logistic regression or
Krumhansl--Schmuckler (KS) matching~\cite{krumhansl1982,krumhansl1990,temperley1999ks}.
KS matching compares the $12$-dimensional pitch-class count vector with the key profiles for the $24$ major and minor keys and predicts the key with the highest correlation.
We evaluate multiple context lengths and use the strongest baseline.
To control for probe capacity, we also train the same probe on a control task with random piece-level key labels~\cite{hewitt2019control}.
We define the \emph{probe margin} as
\begin{equation}
M_{\mathrm{probe}}
=
\left(F_1^{\mathrm{probe}}-F_1^{\mathrm{control}}\right)
-F_1^{\mathrm{note}},
\label{eq:probe-margin}
\end{equation}
where $F_1^{\mathrm{probe}}$ is the macro-$F_1$ for true key labels, $F_1^{\mathrm{control}}$ is that for random labels, and $F_1^{\mathrm{note}}$ is that of the strongest note-counting baseline.
We regard the margin as positive when the lower bound of its piece-level bootstrap $95\%$ confidence interval is above zero.

\noindent\textbf{RQ2.}
% 各介入についてsuccess rate（SR）を求める．
% 介入が成功したとみなすのは，次の2条件を満たす場合である．
% すなわち，KS推定器が生成された続きを目標調と判定し，かつ編集による尤度コストが自然な転調から較正した閾値以下である場合である．
% 第2の条件は，目標調の音階の音を並べただけで音楽として成立していない続きを除外する．
% $H_{\mathrm{ref}}(y\mid x)$を，reference modelの下での，prompt $x$に対する続き$y$のトークン平均負対数尤度とする．
% 編集のコストを，同じpromptのreplacement後の続き$y'$と通常の続き$y$のパープレキシティ差$E$によって測る．
% $E\le 0.613$のとき条件を満たすとする．
% この閾値は，自然な転調における転調前後24トークン窓のパープレキシティ上昇の90パーセンタイルとして較正する．
% 公開モデルでは，代わりに平均負対数尤度の差を用い，閾値は各コーパスについて自然な転調前後の音符トークンで較正し（Bach 0.85，Pop 1.12），別の公開モデルをreference modelとする．
% key-related subspaceに固有の効果を測るため，edit marginを次のように定義する．
% ここで$\mathrm{SR}_{\mathrm{replace}}$と$\mathrm{SR}_{\mathrm{random}}$は，それぞれtarget-key replacementと，同じ次元のrandom-subspace replacementのSRである．
% 主となる合成データのcontinuation test（Fig.~\ref{fig:main-results}左）では，random-subspace replacementはさらに各位置でtarget-key replacementと変位量を合わせる．
% 層走査(層ごとに効果を測った実験)，次音予測の検証，公開モデルの評価では，次元のみを合わせたrandom-subspace replacementを用いる．
We compute the \emph{success rate} (SR) for each intervention.
We count an intervention as successful when two conditions hold. 
The KS estimator must identify the generated continuation as the target key, and the likelihood cost of the edit must not exceed what is typical at a natural key change. 
The second condition excludes continuations that merely scatter pitches from the target-key scale without forming plausible music.
Let $H_{\mathrm{ref}}(y \mid x) = -\frac{1}{|y|}\sum_{j}\log p_{\mathrm{ref}}(y_j \mid x, y_{<j})$ denote the mean token negative log-likelihood of a continuation $y$ given the prompt $x$ under a reference model trained with a different seed on independently generated data.
We measure the cost of the edit by the perplexity difference
\begin{equation}
E = \exp H_{\mathrm{ref}}(y' \mid x) - \exp H_{\mathrm{ref}}(y \mid x)
\end{equation}
between the replacement continuation $y'$ and the original continuation $y$ generated from the same prompt without replacement.
We count the criterion as met when $E \le 0.613$, the 90th percentile of the perplexity rise between 24-token windows before and after natural key changes in the calibration pieces.
For public models, we use the difference in mean negative log-likelihood instead, with a threshold calibrated per corpus on the note tokens around natural key changes (0.85 on Bach, 1.12 on Pop) and a separate public model as the reference.

To measure the effect specific to the key-related subspace, we define the \emph{edit margin} as
\begin{equation}
M_{\mathrm{edit}}
=
\mathrm{SR}_{\mathrm{replace}}
-
\mathrm{SR}_{\mathrm{random}},
\label{eq:edit_margin}
\end{equation}
where $\mathrm{SR}_{\mathrm{replace}}$ and $\mathrm{SR}_{\mathrm{random}}$ are the success rates of target-key replacement and dimension-matched random-subspace replacement, respectively.
In the main synthetic continuation test (Fig.~\ref{fig:main-results}, left), the random-subspace replacement is additionally matched in displacement to the target-key replacement at every position.
The layer scans used to select the intervention layer (Fig.~\ref{fig:layers}), the next-pitch test, and the public-model evaluations use the dimension-matched random-subspace replacement.

\noindent\textbf{Pre-generation pitch prediction.}
% 生成された音符をモデルが読み直した結果として目標調へ変化した可能性を検証するため，新しい音符をサンプリングする前の次音高分布を調べる．
% 9小節目の境界で，小節トークンと位置トークンをteacher forcingで追加し，replacementを適用したうえで，次トークン分布をサンプリングせずに読み取る．
% 調$\kappa$について，$m(\kappa)$を，その調の音階に属する音高トークンへ割り当てられた確率の総和とする．
% 目標調と元の調に共通する音高は，両方の和に数える．
% 目標調$\kappa^*$とプロンプトの元の調$\kappa_0$について，$D$を音階確率の対数比として定義する．
% $\delta D$はreplacementありと通常実行の差であり，$D_{\mathrm{original}}$は同じprompt・同じ位置でreplacementを行わない場合の値である．
We examine the next-pitch distribution before any new note is sampled to test whether the target-key shift appears before the model can infer the target key from its own generated notes.
At the bar-9 boundary, we append the bar and position tokens by teacher forcing, apply the replacement, and read the next-token distribution without sampling.
For key $\kappa$, let $m(\kappa)$ be the total probability assigned to pitch tokens in that key's scale.
Pitches shared by the target-key and prompt-key scales count in both sums.
For target key $\kappa^*$ and prompt key $\kappa_0$, we report the log ratio $D$ and its replacement-induced change $\delta D$, where $D_{\mathrm{original}}$ is computed from the same prompt and position without replacement, as follows.
\begin{equation}
D = \log m(\kappa^*) - \log m(\kappa_0),
\quad
\delta D = D_{\mathrm{replace}} - D_{\mathrm{original}}.
\label{eq:logratio}
\end{equation}

\noindent\textbf{Additional controls and model comparisons.}
% 観測された効果の頑健性と解釈を確認するため，追加分析を行う．
% まず，結果がKS推定器だけに依存していないことを確認するため，生成音符のうち目標調の音階に属する割合であるpitch-in-scale rateを測定する．
% さらに，層およびトークン位置ごとにprobe marginとedit marginを比較し，調情報を読み出しやすい場所と，その情報を変更したときに生成へ強く影響する場所の関係を調べる．
% 同じ評価を公開モデルにも適用し，これらの結果が自作モデルに限定されないかを検証する．
To test the robustness and interpretation of the observed effect, we conduct several additional analyses.
First, we measure the \emph{pitch-in-scale rate}, the fraction of generated notes belonging to the target-key scale, to test whether the result depends on the KS estimator.
We further compare probe margin and edit margin across layers and token positions to examine whether key information is readable at the same locations where changing it most strongly affects generation.
We apply the same evaluation to public models to test whether these findings extend beyond our trained models.

\noindent\textbf{Evaluation prompts.}
% 主実験では，介入層を6,000曲側から取ったpromptで選び，第4層を長調・短調の両方に用いる．
% Final testでは，プロービングに使っていない長調100曲と短調100曲を用い，各promptについて同じ旋法の他の11調へ介入する．
% Table~\ref{tab:public-extra}の追加公開モデルセルでは，20 search promptで層を選び，60 held-out final promptと12 major targetを用いる．
% 生成結果を目標調ごとにまとめ，同じpromptに対するtarget-key replacementと各比較条件を片側Wilcoxon符号順位検定で比較し，12種類の目標調にわたるHolm補正を比較ごとに個別に適用する．
For the synthetic-model experiments, the intervention layer is selected on prompts from the $6{,}000$ probing pieces, giving layer~$4$ for both major and minor prompts.
The final test uses $100$ major-key and $100$ minor-key prompts held out from probing.
For each prompt, we intervene toward the $11$ other keys of the same mode, giving $1{,}100$ continuations per mode.
Each continuation is sampled once with temperature 1.0 and top-$p$ 0.95 for 384 tokens, and the KS estimator is applied once to the pitch-class histogram of the whole continuation, truncated at the end-of-piece token or after 16 bars.
For the deduplicated public-model Bach evaluation (Table~\ref{tab:public-extra}a), probes and target-key means are estimated from $220$ chorales; of the remaining $80$, the first $20$ by chorale number select the layer and the other $60$ are the final prompts, with $12$ major target keys.
The additional cells in Table~\ref{tab:public-extra}b,c use $20$ search and $60$ held-out prompts, with target means estimated from all pieces of the corpus.
For all continuation tests, we group continuations by target key and compare target-key replacement with each comparison condition using a one-sided Wilcoxon signed-rank test on paired prompts, with Holm correction over the $12$ target keys applied separately to each comparison~\cite{holm1979}.

\section{Results}
\label{sec:results}

\subsection{Linear Probing}
\label{sec:h1}
% 調情報は，過去の音高だけを用いるnote-counting baselineよりも，モデルの内部活性から読み取りやすい．
% 第4層では，probeのmacro-F1は0.927であり，最も性能の高いnote-counting baselineの0.824を上回る．
% Control taskによる補正後のprobe marginは+0.071であり，bootstrap 95\%信頼区間は[0.056, 0.081]である．
The key is more linearly accessible from the internal activations than from the note-counting baselines.
At layer~$4$, the probe reaches macro-$F_1$ $0.927$, compared with $0.824$ for the strongest note-counting baseline.
After correcting for the control task, the probe margin is $+0.071$, with a bootstrap $95\%$ confidence interval of $[0.056,0.081]$.

\subsection{Continuation Generation}
\label{sec:h3}
% 調関連成分を目標調のものに置き換えると，生成音楽は目標調に従いやすくなる（Fig.~\ref{fig:main-results}左）．
% SRは，各継続についてKS推定と尤度基準のANDを直接数えた値である．
% ReplacementのSRはmajorで35.5\%，minorで49.5\%であり，対応するmatched random-subspace replacementの5.6\%，2.6\%を上回る．
% 両modeでrandom-subspace replacementを大きく上回り，12個すべての目標調で有意な改善を示す．
% 同じ傾向はpitch-in-scale rateでも見られ，閾値を変えてもreplacementはすべての比較条件を上回る．
% したがって，効果は調推定器や特定の尤度閾値だけに依存しない．
Replacing the key-related component with that of the target key makes the generated continuation more likely to follow the target key (Fig.~\ref{fig:main-results}, left).
The joint success rate is counted directly per continuation as the conjunction of target-key KS agreement and the likelihood criterion, not by multiplying aggregate component rates.
Replacement reaches $35.5\%$ in major and $49.5\%$ in minor, compared with $5.6\%$ and $2.6\%$ for the matched random-subspace replacement.
It substantially exceeds the random-subspace replacement in both modes and shows a significant improvement for all $12$ target keys.
The same pattern appears in the \emph{pitch-in-scale rate}, and the replacement stays above every comparison condition at each threshold from $0.2$ to no threshold at all.
The effect therefore does not depend on the key estimator or on the particular likelihood threshold.
Across all six trained models, each at the layer selected on its own search prompts, replacement reaches $0.231$--$0.355$ in major and $0.280$--$0.495$ in minor (means $0.279$ and $0.366$) against at most $0.056$ for the matched control, significant for all $12$ keys in every model; the main model is the strongest run.
Without intervention, the estimator returns the prompt's key for $0.580$ of major and $0.840$ of minor continuations and a given other key for $0.033$ and $0.000$.
Removing from $V_\ell$ the one direction that leaves the probe softmax unchanged (rank $23$) gives $0.368$ and $0.461$.

% この効果は，直近の音高クラス頻度の線形な符号化によるものでもない．
% 同じ目標値を，直近の音高クラスヒストグラムを予測するように当てはめた部分空間を通して書き込むと，成功率はmajorで0.027，minorで0.003にとどまり，同じ次元のランダム対照と区別できない．
% 逆に，$V_\ell$からその部分空間の成分を取り除いた残りを通して書き込んでも，効果は0.360と0.478で保たれる．
% したがって介入が働くのは，音高クラス頻度では説明できない$V_\ell$の部分を通してである．
The effect is not carried by a linear encoding of recent pitch-class frequency either.
Writing the same target through a subspace fitted to predict the recent pitch-class histogram reaches only $0.027$ in major and $0.003$ in minor, which is indistinguishable from a random subspace of the same rank.
Writing through $V_\ell$ with that subspace removed instead retains the full effect ($0.360$ and $0.478$).
The intervention therefore acts through the part of $V_\ell$ that pitch-class frequency does not explain.

\subsection{Pitch Prediction Before Sampling}
\label{sec:nextpitch}
% Activation patchingは，モデルが新しい音符をサンプリングする前から音高予測にも影響する（Fig.~\ref{fig:main-results}右）．
% 最初の介入位置において，$D$の変化量は，majorのpromptではreplacementで$+0.695$，次元を合わせたrandom-subspace replacementで$+0.041$，minorのpromptではそれぞれ$+0.309$と$+0.026$である．
% この差は，両modeとも12個すべての目標調で有意である．
% この時点では編集後の音符がまだ存在しないため，この効果はモデルが自分で生成した音符から目標調を読み取った結果では説明できない．
Activation patching also affects pitch prediction before the model samples any new note (Fig.~\ref{fig:main-results}, right).
At the first intervention position, the change in $D$ (Eq.~\ref{eq:logratio}) is $+0.695$ for replacement and $+0.041$ for the dimension-matched random-subspace replacement on major prompts, and $+0.309$ and $+0.026$ on minor prompts.
The difference is significant for all $12$ target keys in both modes.
Because no new note has been sampled after the intervention at this point, the effect cannot be explained by the model reading the target key from its own generated notes.

\subsection{Layerwise Comparison}
\label{sec:h5}
% Probe marginとedit marginは層によって異なる変化を示す．
% 第0--1層では両者とも小さいが，第2層以降ではprobe marginは正となり， 層間で比較的小さな変化を示す．
% 一方，edit marginは層によって大きく変化し，第4層で最大となる．
% したがって，probe marginが正であることだけでは，その層への介入が生成にどの程度強く影響するかは分からない．
Probe margin and edit margin show different layer-wise variation.
Both are small in the first two layers, whereas probe margin becomes positive from layer~$2$ onward and varies relatively little across the deeper layers.
In contrast, edit margin varies more strongly across layers and reaches its maximum at layer~$4$ (Fig.~\ref{fig:layers}).
Therefore, even among layers from which key is linearly readable, the intervention effect is not uniform and must be measured directly.
Additional token-position controls indicate that the effective positions are those immediately preceding a pitch decision.

\subsection{Public Models}
\label{sec:public}
% 実音楽で学習された公開モデルでも同じ傾向が現れるかを調べるため，Bachの公開モデル評価でFig.~\ref{fig:main-results}と同じ二つの評価を行う．
% AMT-12L，REMI+，MMTでは，継続生成のsuccess rateにおいてreplacementが次元を合わせたrandom-subspace replacementを上回る．
% 同じ評価で，サンプリング前の次音高対数比もreplacementによって目標調側へ動く．
% ただしAMT-12Lではサンプリング前の変化は小さく，次音高分布への即時的な変化は弱い一方で，反復介入は継続生成全体に影響する．
% 全層走査では効果は一様でなく，AMT-12LとREMI+ではedit marginのピークとprobe marginのピークが一致しない．
% PopおよびAMTのモデルサイズ比較に関する追加の継続生成結果はTable~\ref{tab:public-extra}にまとめる．
To test whether the same pattern appears in public models trained on real music, we repeat the two evaluations from Fig.~\ref{fig:main-results} on the deduplicated Bach evaluation (Table~\ref{tab:public-extra}a).
At the layer selected on the search chorales, replacement exceeds the dimension-matched random-subspace replacement on all $12$ target keys in AMT-12L, MMT, and REMI+, and shifts the next-pitch log ratio before sampling on the same $60$ prompts.
The before-sampling shift is small in AMT-12L, indicating that the immediate next-pitch distribution changes weakly even though repeated intervention still affects the generated continuation.
Writing the same target through a subspace fitted to the recent pitch-class histogram ($\mathrm{SR}_{\mathrm{pc}}$) reaches $0.075$ in REMI+ and $0.178$ in AMT-12L but $0.319$ in MMT, so the pitch-class control that is inert in our model is not inert in every public model, although it stays well below replacement through $V_\ell$ in all three; conversely, removing that subspace from $V_\ell$ keeps $0.567$ in REMI+ but leaves only $0.106$ in AMT-12L.
The associated all-layer scans are non-uniform.
In AMT-12L, the edit-margin peak is layer~$8$ while the probe-margin peak is layer~$9$, and in REMI+ they peak at layers~$5$ and $1$.
These results support the same conclusion as Fig.~\ref{fig:layers}.
Probe performance and intervention effects should be measured separately.

\section{Limitations}
\label{sec:limitations}
% 本研究の結論は，評価したモデル・データ・介入の範囲に限られ，人間と同じ調理解を示すものではない．
% 合成データでは調が潜在変数として使われるため，実音楽より調表現が形成されやすい可能性がある．また主結果は，augmentationありの3 seedの中で最もsuccess rateが高いrunに基づく．
% 置換は同定した成分が生成に影響することを示すが，その成分が調予測に必要であることは示さない．層走査は探索的であり，層間差について多重比較補正した検定は行っていない．
% サンプリング前評価は3つのBach公開モデルに限られ，その他の公開モデル条件は継続生成のみで評価している．調推定精度と継続長はコーパス・トークナイザで異なるため，公開モデルは各自のrandom-subspace replacementと比較する．
% reference modelの尤度基準は知覚品質の評価ではなく，聴取実験も行っていない．
% $V_\ell$はプローブで定義された部分空間なので，すべての調情報を含むとは限らず，調以外の情報も含みうる．また$W_\ell$の行空間にはsoftmax予測に影響しない1方向が含まれる．この方向を除いた場合の生成結果は未検証である．
Our conclusions are limited to the tested models, data, and interventions, and do not establish human-like understanding of key.
The synthetic generator uses key as a latent variable, which may make key representations easier to learn than in real music.
Replacement shows that the identified component affects generation, but not that it is necessary for tonal prediction.
The layer scans are exploratory, without corrected tests of between-layer differences, and both measures peak at the same layer in our model.
The before-sampling evaluation covers only three Bach public models.
The other public-model cells are continuation-only.
Because key-estimation accuracy and continuation length differ across corpora and tokenizers, each public model should be interpreted relative to its own matched random-subspace replacement.
The reference-model likelihood criterion is not a perceptual-quality measure, and we did not run a listening test.
Finally, as a probe-defined subspace, $V_\ell$ need not contain all key information in $h_\ell(t)$ and may include information unrelated to key.

\section{Conclusion}
% 本研究では，音楽Transformerが調を表現し，生成中にそれを使っているかを検証した．
% 調表現を置き換えると，新しい音符をサンプリングする前に次の音高の予測が目標調へ移り，生成された続きが目標調に従う割合が増加する．
% 一方で，プローブ性能だけでは介入の効果は決まらず，その強さは層やモデルによって異なる．
% したがって，内部表現から情報を読み取れることと，モデルがそれを生成中に使っていることは，別々に測定する必要がある．
We asked whether music Transformers represent musical key and use it during generation.
Replacing the key representation shifts next-pitch prediction toward the target key before any new note is sampled and increases target-key following in the generated continuation.
However, probe performance alone does not determine the effect of an intervention, whose strength varies across layers and models.
Reading information from an internal representation and using it during generation must therefore be measured separately.
