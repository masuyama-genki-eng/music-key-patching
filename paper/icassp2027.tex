\begin{abstract}
% Transformerに基づく記号音楽生成モデルが，内部活性に調情報を表現し，その情報を生成に利用しているかを調べる．
% 調を明示するラベルやトークンを含まない記号音楽でTransformerを学習し，線形プロービングによって調関連部分空間を求める．
% 生成中に，この部分空間の成分を現在の調から目標調のものへ置き換える．
% この置き換えにより，majorでは約3本に1本，minorでは約2本に1本が目標調に従うのに対し，対応するrandom-subspace controlでは約18本に1本と約40本に1本にとどまる．
% また，新しい音符を生成する前から目標調の音高へ確率が移動し， 同様の編集効果は実音楽で学習された5つの公開モデルでも確認される．
% 一方，調情報を読み取りやすい層と，編集が強く効く層は必ずしも一致しない．
% これらの結果は，音楽Transformerが生成に影響する置き換え可能な調情報を内部に表現していることを示す．
We investigate whether Transformers for symbolic music generation represent musical key in their internal activations and use this information during generation.
We train Transformers on symbolic music without explicit key labels or tokens and use linear probing to identify a key-related subspace.
During generation, we replace the component in this subspace for the current key with that for a target key.
Roughly one in three generated pieces in major and one in two in minor follow the target key, compared with about one in eighteen and one in forty under a matched random-subspace control.
The intervention shifts probability toward the target key before any new note is generated, and the patching effect also appears in five publicly available models trained on real music.
However, the layers where key information is easy to read are not necessarily those where patching has the strongest effect.
These results show that music Transformers represent replaceable key information that affects generation.
\end{abstract}


\begin{keywords}
symbolic music generation, controllable music generation, activation patching, mechanistic interpretability
\end{keywords}

\section{Introduction}
% 背景
% 近年，Transformerを用いた音楽生成モデルは，長期的な構造を持つ音楽を生成できるようになっている．
% しかし，これらのモデルが内部にどのような音楽情報を持ち，その情報を生成時にどのように使っているかは十分に分かっていない．
% 内部の情報が生成にどのように影響するかを理解することは，生成過程の理解だけでなく，音楽属性の制御にも重要である．
Transformer-based music generation models can generate music with long-term structure~\cite{huang2019musictransformer,thickstun2023anticipatory,dong2023mmt}.
However, we still do not fully know what musical information these models maintain internally or how they use it during generation.
Understanding how internal information affects generation is important for both understanding the generation process and controlling musical attributes.

% 現状
% 内部表現の解析には線形プロービングが，生成結果の制御にはactivation steeringが用いられている．
% Transformerでは，各層が生成途中に数値ベクトルを計算しており，本研究ではこれを内部活性と呼ぶ．
% 線形プローブは，内部活性から属性を予測する分類器を学習し，その予測性能から属性に関する情報をどの程度読み取れるかを調べる．
% 音楽生成モデルについても，線形プロービングを用いて音楽属性を解析する研究が行われている．
% Activation steeringは，目標属性に対応する方向を内部活性に加えることで生成結果を変化させる．
% 音楽生成モデルについても，activation steeringを用いて音楽属性を制御する研究が行われている．
% このように，内部活性から音楽情報を読み取る方法と，内部活性を変更して生成結果を制御する方法の両方が研究されている．
Linear probing is used to analyze internal representations, and activation steering is used to control model outputs.
At each layer, a Transformer computes a vector during generation, which we call an internal activation.
A linear probe learns a classifier that predicts an attribute from an internal activation, and its performance shows how easily information about the attribute can be read from the activation~\cite{alain2017probes,belinkov2022probing}.
Studies on music generation models have also used linear probing to analyze musical attributes~\cite{syntheory2024,ma2024root,mimidi2026}.
Activation steering changes an internal activation by adding a direction associated with a target attribute~\cite{li2023iti,zou2023repe}.
Studies on music generation models have also used activation steering to control musical attributes~\cite{smitin2024,musicrfm2026,singh2026discovering,mimidi2026}.
Thus, prior work has studied both reading musical information from internal activations and controlling generated music by modifying those activations.

% 問題
% しかし，線形プロービングとactivation steeringだけでは，内部の属性情報が実際の生成に使われているかを十分に検証できない．
% 属性を内部活性から高精度に予測できても，モデルがその情報を使って次の出力を生成しているとは限らない．
% また，activation steeringは，元の属性の情報を残したまま目標属性に対応する方向を加える．
% そのため，元の属性と目標属性の影響が混ざり，生成結果だけからそれぞれの影響を分けることは難しい．
% したがって，属性情報を内部から読み取れるかだけでなく，その情報を別の属性に対応する情報へ置き換えたときに生成結果が変化するかを検証する必要がある．
However, linear probing and activation steering alone do not fully test whether internal attribute information is actually used for generation.
A probe may accurately predict an attribute without showing that the model uses this information to generate the next output~\cite{belinkov2022probing}.
Activation steering also keeps information about the original attribute while adding a direction associated with the target attribute~\cite{li2023iti,zou2023repe}.
As a result, the effects of the original and target attributes can remain mixed, making it difficult to separate their effects from the generated output alone.
Therefore, we need to test not only whether attribute information can be read from internal activations but also whether replacing it with information for another attribute changes the generated output.

% 提案
% そこで本研究では，音楽属性の一つである調を対象とする．
% 調にはハ長調やイ短調などがあり，曲の中でどの音高が使われやすいかに関わる基本的な音楽属性である．
% 音楽生成モデルは生成中に音高を選択し，生成された音符から調を推定できる．
% そのため，調は，内部の調情報が実際の生成に使われているかを検証しやすい属性である．
% 本研究では，この調情報が生成に使われているかを検証するためにactivation patchingを用いる．
% Activation patchingとは，モデルへの入力を変えずに内部活性を置き換え，その置き換えが生成結果に与える影響を調べる方法である．
% 具体的には，現在の調に対応する成分を目標調に対応する成分へ置き換え，その置き換えによって生成音楽が目標調に従うかを調べる．

We focus on musical key as the target attribute.
Keys such as C major and A minor affect which pitches are likely to appear in a passage.
Music generation models select pitches during generation, and we can estimate the key from the generated notes.
Therefore, key is suitable for testing whether internal key information is actually used for generation.
We use activation patching to test whether the model uses this key information.
Activation patching replaces an internal activation without changing the model input and examines how this replacement affects the generated output~\cite{geiger2021causal,geiger2024das}.
Specifically, we replace the component associated with the current key with that associated with a target key and test whether this replacement makes the generated music follow the target key.

% 本論文は生成手法の提案ではなく，モデル内部の分析を目的とする．
% 本研究の貢献は次の2点である．
This is an analysis, not a generation method.
We make two contributions.
\begin{itemize}
% 内部の調情報を置き換えると，音符を生成する前から音高予測が変化し，生成音楽が目標調に従いやすくなることを示す．
% また，この目標調への変化は，5つの公開モデルでも確認される．
% 調情報を読み取りやすい層と，その情報を置き換えたときに生成音楽の調が変化しやすい層は，必ずしも一致しないことを示す．
\item We show that replacing internal key information shifts pitch prediction before generation and makes the generated music more likely to follow the target key.
The target-key effect also appears in five publicly available models.
\item We show that the layers where key information is easy to read are not always the layers where replacing it changes the generated key.
\end{itemize}

\section{Method}
\label{sec:method}
% 内部活性から調情報を読み取れるだけでは，その情報が実際の生成に使われているとは判断できない．
% そこで本研究では，まず線形プロービングによって調情報を読み取れる内部表現を特定し，次にactivation patchingによってその表現を変更したときに生成音楽が変化するかを検証する．
Reading key information from an internal activation does not show that the model uses this information for generation.
We therefore first use linear probing to identify internal representations from which key information can be read and then use activation patching to test whether changing these representations affects the generated music.

\subsection{Linear Probing}
\label{sec:probe}
% 線形プロービングを，12種類の主音と長短を組み合わせた24種類の調を予測する多クラス分類タスクとして定式化する．
% 層$\ell$のTransformer blockの出力における位置$t$の内部活性を$h_\ell(t)$とする．
% プローブは$h_\ell(t)$を入力とし，その位置の正解調$\kappa(t)$を予測する．
% 分類器には多項ロジスティック回帰を用いる．
% 分類器は，次式で表される24種類の調に対する予測確率分布$p_\ell(t)$を出力する．
% $W_\ell$と$b_\ell$は分類器の学習可能なパラメータであり，正解調$\kappa(t)$を予測するように学習する．
% この線形プローブにより，各Transformer blockの出力から調情報をどの程度線形に読み出せるかを定量化できる．
We formulate linear probing as a 24-class key classification task covering 12 tonics in major and minor modes.
We denote the internal activation at position $t$ from the output of Transformer block $\ell$ by $h_\ell(t)$.
The probe takes $h_\ell(t)$ as input and predicts the true key $\kappa(t)$.
We use multinomial logistic regression as the classifier.
The classifier outputs a probability distribution $p_\ell(t)$ over the $24$ keys given by
\begin{equation}
p_\ell(t)
=
\operatorname{softmax}
\left(
W_\ell h_\ell(t)+b_\ell
\right),
\label{eq:probe}
\end{equation}
where $W_\ell$ and $b_\ell$ are learnable parameters trained to predict the true key $\kappa(t)$.
This linear probe allows us to quantify how linearly accessible key information is from the output of each Transformer block.

\subsection{Activation Patching}
\label{sec:patching}
% Activation patchingでは，現在の内部活性の調に関する成分を，目標調で得られた内部活性の対応する成分に置き換える．
% 層$\ell$では，線形プローブの24調に対応する重みベクトルから正規直交基底$V_\ell$を構成する．
% この基底は，プローブが24調を識別するために用いる部分空間を定める．
% $P_{V_\ell}=V_\ell V_\ell^\top$は，内部活性をこの部分空間へ射影する．
% 目標調$\kappa^*$について，その調に属する内部活性を平均し，$\mu_{\ell,\kappa^*}$を求める．
% プローブの重みは置き換える部分空間を定め，目標調の平均活性は置き換え先を定める．
% 8小節のプロンプトを入力し，9小節目以降では，現在の内部活性の対応する成分を目標調の成分に置き換える．
% 以上により，線形プロービングで読み出した調表現を，生成中に直接変更できる．
Activation patching replaces the key-related component of the current activation with the corresponding component of an activation observed for a target key.
For layer $\ell$, we construct an orthonormal basis $V_\ell$ from the probe weight vectors for the $24$ keys.
This basis defines the subspace used by the probe to distinguish keys.
We define
\begin{equation}
P_{V_\ell}
=
V_\ell V_\ell^\top,
\label{eq:projector}
\end{equation}
which projects an activation onto this subspace.
For target key $\kappa^*$, we average the corresponding internal activations to obtain $\mu_{\ell,\kappa^*}$.
The probe weights define the subspace to replace, while the target-key mean defines the replacement value.
We give the model an eight-bar prompt and apply the replacement from bar~9 onward as
\begin{equation}
h'_\ell(t)
=
h_\ell(t)
-
\underbrace{P_{V_\ell}h_\ell(t)}_{\text{remove}}
+
\underbrace{P_{V_\ell}\mu_{\ell,\kappa^*}}_{\text{insert}}.
\label{eq:edit}
\end{equation}
This formulation allows us to directly modify the key representation identified by linear probing during generation, leaving the input and all other components unchanged (Fig.~\ref{fig:overview}).

\section{Experimental Setup}
\label{sec:setup}

\subsection{Data}
\label{sec:data}
% 主実験では，各トークンの正確な調ラベルを得るために合成音楽を用いる．
% 学習用に200,000曲，検証用とテスト用にそれぞれ10,000曲を生成し，各楽曲には0--3回の転調を含める．
% 語彙には小節，位置，絶対MIDI音高，音長を含むが，調やコードの記号は含まない．
% 合成データで得られた結果が実音楽にも当てはまるかを確認するため，人手による調ラベルを持つ実音楽でも評価する．
% BachではWhen in Romeの300曲のコラールを用いる．
% POP909-CLでは，注釈に欠損または不整合がある4曲を除いた909曲中905曲を用いる．
We use synthetic music for the main experiments to obtain exact key labels at every token.
We generate $200{,}000$ training pieces and $10{,}000$ pieces each for validation and test, with $0$--$3$ key changes per piece.
The vocabulary includes bars, positions, absolute MIDI pitches, and note lengths, but no key or chord symbols.
To test whether the findings extend to real music, we also evaluate models trained on datasets with human key annotations.
We use $300$ Bach chorales from When in Rome~\cite{gotham2023wir} and $905$ of the $909$ songs in POP909-CL~\cite{pop909cl2026}, excluding four songs with missing or inconsistent annotations.

\subsection{Models}
\label{sec:models}
% 主実験には，8層，512次元の内部活性，約25Mパラメータを持つGPT-2型decoderを用いる．
% 同じアーキテクチャについて，異なる学習条件で学習した5つの追加モデルも用いる．
% 実音楽で学習されたモデルの評価には，5つの公開checkpointを用いる．
% AMTでは12層，24層，36層の3つのcheckpointを用いる．
% さらに，MMTと，MMTとともに公開されたREMI baselineを用いる．
Our main model is an $8$-layer GPT-2-style~\cite{radford2019gpt2} decoder with $512$-dimensional activations and about $25$M parameters.
We use five additional models with the same architecture trained under different settings.
For evaluation on real music, we use five publicly available checkpoints.
These include $12$-, $24$-, and $36$-layer Anticipatory Music Transformer (AMT) checkpoints~\cite{thickstun2023anticipatory}.
We further use the Multitrack Music Transformer (MMT)~\cite{dong2023mmt} and the REMI baseline released with MMT.

\subsection{Evaluation Protocol}
\label{sec:measures}
% 評価では，二つの研究質問を検証する．
% RQ1：内部活性から，過去の音高だけでは説明できない調情報を読み出せるか？
% RQ2：内部の調関連成分を目標調のものに置き換えると，同程度のランダム部分空間の置き換えよりも，生成された続きを目標調へ変化させられるか？
% これら二つの研究質問により，調情報が単に内部活性から読み出せるだけなのか，それともその表現を置き換えることで生成に影響する形で保持されているのかを区別する．
% さらに，統制実験と層・トークン位置ごとの分析を行い， 観測された効果に対する別の説明を検証するとともに，読み取りやすさと編集可能性が一致する場所と異なる場所を調べる．
% すべての評価基準と閾値はfinal testの前に固定する．
We structure the evaluation around two research questions:
\begin{itemize}
    \item \textbf{RQ1:} Can key information be read from internal activations beyond what can be inferred from preceding pitches?
    \item \textbf{RQ2:} Does replacing the internal key-related component with that of a target key shift the generated continuation toward the target key more than a matched random-subspace replacement?
\end{itemize}
Together, these questions distinguish whether key information is merely readable from internal activations or is represented in a form whose replacement affects generation.
We further use control experiments and layer- and token-position analyses to test alternative explanations and examine where readability and editability coincide or differ.
All evaluation criteria and thresholds are fixed before the final test.

\noindent\textbf{RQ1:}
% まず，内部活性から24調のいずれかを予測する線形プローブを学習し， macro-F1で性能を評価する．
% この性能が過去の音高だけで説明できるかを確認するため，それ以前の音高トークンから12種類のpitch classを数えるnote-counting baselineと比較する．
% Baselineにはロジスティック回帰とKrumhansl--Schmuckler（KS）法を用い，複数の履歴長の中で最も性能の高いものを比較対象とする．
% KS法は，12次元のpitch-class count vectorと24調それぞれのkey profileとの相関を計算し，最も相関が高い調を予測する．
% また，プローブ自体の表現力による影響を補正するため，各曲にランダムな調ラベルを割り当てたcontrol taskでも同じプローブを学習する．
% Probe marginを M_probe = (F1_probe - F1_control) - F1_noteと定義する．
% ここで，F1_probeは実際の調分類，F1_controlはランダムラベルのcontrol task，F1_noteは最も性能の高いnote-counting baselineのmacro-F1である．
% 各曲を単位としたブートストラップによる95%信頼区間の下限が0を上回る場合，probe marginは正であると判断する
We train a linear probe to predict one of the $24$ keys from the internal activation at each position and evaluate it using macro-$F_1$.
To test whether this performance can be explained by preceding pitches, we compare it with note-counting baselines.
The baselines count the $12$ pitch classes in preceding pitch tokens and predict the key using logistic regression or
Krumhansl--Schmuckler (KS) matching~\cite{krumhansl1982,krumhansl1990,temperley1999ks}.
KS matching compares the $12$-dimensional pitch-class count vector with the key profiles for the $24$ major and minor keys and predicts the key with the highest correlation.
We evaluate multiple context lengths and use the strongest baseline.
To control for probe capacity, we also train the same probe on a control task with random piece-level key labels~\cite{hewitt2019control}.
We define the \emph{probe margin} as
\begin{equation}
M_{\mathrm{probe}}
=
\left(F_1^{\mathrm{probe}}-F_1^{\mathrm{control}}\right)
-F_1^{\mathrm{note}},
\label{eq:probe-margin}
\end{equation}
where $F_1^{\mathrm{probe}}$ is the macro-$F_1$ for true key labels, $F_1^{\mathrm{control}}$ is that for random labels, and $F_1^{\mathrm{note}}$ is that of the strongest note-counting baseline.
We regard the margin as positive when the lower bound of its piece-level bootstrap $95\%$ confidence interval is above zero.

\noindent\textbf{RQ2:}
% 各介入についてsuccess rate（SR）を求める．
% KS推定器が生成された続きを目標調と判定し，かつlikelihoodの変化が自然な転調で観測される範囲内である場合を成功とする．
% 自作モデルでは，異なるseedと重複しないデータで学習したreference modelを用いてlikelihoodの変化を測定する．
% 自然な転調で観測されたlikelihood変化の90パーセンタイルである0.613を閾値とする．
% 公開モデルでは，各コーパスについて別のreference modelを用いて閾値を再計算する．
% 調関連部分空間に特有の効果を評価するため，replacementのSRと，同じ次元数を持つ
% random-subspace replacementのSRとの差をedit marginとして定義する．
% 変位量まで揃えた統制は，選択した層でのみ用いる（Table 1）．
We compute the \emph{success rate} (SR) for each intervention.
We count an intervention as successful when the KS estimator identifies the generated continuation as the target key and the likelihood change remains within the range observed at natural key changes.
For our trained models, we measure the likelihood change using a reference model trained with a different seed on a disjoint data split.
We use $0.613$, the $90$th percentile of the likelihood change observed at natural key changes, as the threshold.
For public models, we recompute this threshold for each corpus using a separate reference model.
To measure the effect specific to the key-related subspace, we define the \emph{edit margin} as
\begin{equation}
M_{\mathrm{edit}}
=
\mathrm{SR}_{\mathrm{replace}}
-
\mathrm{SR}_{\mathrm{random}},
\label{eq:edit_margin}
\end{equation}
where $\mathrm{SR}_{\mathrm{replace}}$ and $\mathrm{SR}_{\mathrm{random}}$ are the success rates of target-key replacement and of a random-subspace replacement of the same dimension, respectively.
A positive edit margin indicates that target-key replacement is more effective than the random-subspace intervention.
At the selected layer we additionally match the activation displacement of the random subspace to that of the replacement (Table~\ref{tab:main}).

\noindent\textbf{Controls and additional analyses.}
% まず，結果がKS推定器だけに依存していないことを確認するため，生成音符のうち目標調の音階に属する割合であるpitch-in-scale rateも測定する．
% 次に，生成された音符をモデルが読み直した結果として目標調へ変化した可能性を検証するため，新しい音符が生成される前の次音高分布を調べる．
% さらに，層およびトークン位置ごとにprobe marginとedit marginを比較し，調情報を読み出しやすい場所と，その情報を変更したときに生成へ強く影響する場所の関係を調べる．
% 同じ評価を公開モデルにも適用し，これらの結果が自作モデルに限定されないかを検証する．
% 最後に，replacementとactivation steeringを比較し，元の調関連成分を置き換える効果と，目標調成分を単純に加算する効果を区別する．
To test the robustness and interpretation of the observed effect, we conduct several additional analyses.
First, we measure the \emph{pitch-in-scale rate}, the fraction of generated notes belonging to the target-key scale, to test whether the result depends on the KS estimator.
We then examine the next-pitch distribution before any new note is generated to test whether the target-key shift appears before the model can infer the target key from its own generated notes.
We further compare probe margin and edit margin across layers and token positions to examine whether key information is readable at the same locations where changing it most strongly affects generation.
We apply the same evaluation to publicly available models to test whether these findings extend beyond our trained models.
Finally, we compare replacement with activation steering to distinguish replacing the original key-related component from simply adding a target-key component.

\noindent\textbf{Search and final test.}
% 自作のGPT-2型モデルでは，Search stageで100個のpromptを用いて介入設定を選択し，最終評価で用いる層を第4層に固定する．
% Final testでは，probeの学習にも介入設定の選択にも使用していない100個のpromptを用いて，Search stageで選択した設定を評価する．
% 各promptについて，同じmajor/minor mode内で元の調を除く11種類の目標調へ介入し，各条件で合計1,100個の生成結果を評価する．
% 介入設定はmajorのpromptを用いて選択し，minorでは追加の設定選択を行わず， majorで選択した設定をそのまま使用する．
% 12種類の各目標調について，同じpromptに対するtarget-key replacementとrandom-subspace replacementを片側Wilcoxon符号順位検定で比較し，12個の目標調に対してHolm補正を適用する．
For our GPT-2-style models, we use $100$ prompts in the search stage to select the intervention setting and choose layer~$4$ for the final evaluation.
We then evaluate the selected setting on $100$ unseen prompts used for neither probe training nor intervention selection.
For each prompt, we intervene toward the $11$ other target keys within the same major or minor mode, giving $1{,}100$ generated continuations per condition.
We select the intervention setting using major-key prompts and apply the same setting to minor-key prompts without additional selection.
For each of the $12$ target keys, we compare target-key replacement with the random-subspace replacement using a one-sided Wilcoxon signed-rank test on paired prompts and apply Holm correction over the $12$ target keys~\cite{holm1979}.

% IV. 結果
\section{Results}
\label{sec:results}

\subsection{Linear Probing}
\label{sec:h1}
% 調情報は，過去の音高だけを用いるnote-counting baselineよりも，モデルの内部活性から読み取りやすい．
% 第4層では，probeのmacro-F1は0.927であり，最も性能の高いnote-counting baselineの0.824を上回る．
% Control taskによる補正後のprobe marginは+0.071であり，bootstrap 95\%信頼区間は[0.056, 0.081]である．
The key is more linearly accessible from the internal activations than from the note-counting baselines.
At layer~$4$, the probe reaches macro-$F_1$ $0.927$, compared with $0.824$ for the strongest note-counting baseline.
After correcting for the control task, the probe margin is $+0.071$, with a bootstrap $95\%$ confidence interval of $[0.056,0.081]$.

\subsection{Activation Patching}
\label{sec:h3}
% 調関連成分を目標調のものに置き換えると，生成音楽は目標調に従いやすくなる（Table~\ref{tab:main}）．
% Replacementは，majorとminorの両方でmatched random-subspace controlを大きく上回り， 12個すべての目標調で有意な改善を示す．
% また，pitch-in-scale rateでも同じ傾向が得られる．
% したがって，目標調への変化はKS推定器だけに依存した結果ではない．
Replacing the key-related component with that of the target key makes the generated music more likely to follow the target key (Table~\ref{tab:main}).
Replacement substantially outperforms the matched random-subspace control in both major and minor settings and shows a significant improvement for all $12$ target keys.
The same pattern appears in the \emph{pitch-in-scale rate}, showing that the shift toward the target key does not depend only on the KS estimator.

\subsection{Activation Patching Affects Pitch Prediction Before Generation}
\label{sec:nextpitch}
% Activation patchingは，モデルが新しい音符を生成する前から音高予測に影響する．
% 最初の編集位置では，目標調の音階に割り当てられる確率が，元の調の音階に割り当てられる確率に対して相対的に増加する．
% この変化を両者の確率質量の対数比の変化として測定すると，replacementでは0.695，random-subspace controlでは0.041となる．
% この差は12個すべての目標調で有意である．
% この時点では編集後の音符がまだ存在しないため，この効果はモデルが自分で生成した音符から目標調を読み取った結果では説明できない．
Activation patching affects pitch prediction before the model generates any new note.
At the first intervention position, replacement shifts probability toward pitches in the target-key scale relative to pitches in the original-key scale.
We quantify this shift as the change in the log ratio of probability mass on the target-key scale to that on the original-key scale.
This value is $0.695$ for replacement and $0.041$ for the random-subspace control.
The difference is significant for all $12$ target keys.
Because no new note has been generated after the intervention at this point, the effect cannot be explained by the model reading the target key from its own generated notes.

\subsection{Probe Margin Does Not Fully Predict Edit Strength}
\label{sec:h5}
% Probe marginとedit marginは層によって異なる変化を示す．
% 第0層のprobe marginは負で，第1層でもまだ正にならず，edit marginはどちらの層でも小さい．
% 第2層以降ではprobe marginは正となり，層間で比較的小さな変化を示す．
% 一方，edit marginは層によって大きく変化し，第4層で最大となる．
% したがって，probe marginが正であることだけでは，その層への介入が生成にどの程度強く影響するかは分からない．
Probe margin and edit margin show different layer-wise variation.
Probe margin is negative at layer~$0$ and not yet positive at layer~$1$, and edit margin is small at both; from layer~$2$ onward probe margin is positive and varies relatively little across the deeper layers.
In contrast, edit margin varies more strongly across layers and reaches its maximum at layer~$4$ (Fig.~\ref{fig:readuse}).
Thus, a positive probe margin alone does not determine how strongly an intervention at that layer affects generation.

% トークン位置についても，介入効果は位置によって大きく異なる．
% 音高位置だけを編集した場合のsuccess rateは0.035であるのに対し，小節と音長の位置だけを編集した場合は0.233となる．
% したがって，調関連情報への介入効果は層だけでなくトークン位置にも依存する．
Edit effectiveness also depends strongly on token position.
Patching only pitch positions reaches a success rate of $0.035$, whereas patching only bar and note-length positions reaches $0.233$.
Thus, the effect of changing key-related information depends on both layer and token position.

\subsection{Probe Performance and Patching Effect Do Not Necessarily Agree in Public Models}
\label{sec:wild}
% Read--use gapは，実音楽で学習された公開モデルでも確認できる（Table~\ref{tab:wild}）．
% Bachでは，AMT，MMT，REMIのすべてでprobe marginが正となり，activation patchingはすべての目標調でrandom-subspace controlを上回る．
% また，評価したAMTの異なるモデルサイズでも同じ傾向が得られる．
% 一方，Popではprobe performanceとpatching effectは一致しない．
% AMTは最も高いprobe marginを示す一方でpatching success rateは最も低く，MMTとREMIはprobeではnote-counting baselineを上回らないが，
% activation patchingではすべての目標調でrandom-subspace controlを上回る．
% したがって，公開モデルにおいても，probe performanceとpatching effectは必ずしも一致しない．
% 追加分析でも同じ傾向が得られる．
% Bachでは，replacementは新しい音符を生成する前から次に生成される音高の確率分布を目標調の方向へ変化させるが，random subspaceでは同程度の変化は見られない．
% また，AMTとREMIでは音高位置だけを編集してもほとんど効果がない一方，音高の直前にある構造的な位置への編集は，
% 制限なしの編集と同程度の効果を示す．
% さらにAMT-12Lでは，edit marginは第8層で最大となる一方，probe marginは第10層で最大となる．
% Sec.~\ref{sec:h5}の結果と合わせると，probe性能だけでは，調情報の変更が生成に強く影響する場所を特定できない．

A similar difference between probe performance and patching effect appears in publicly available models trained on real music (Table~\ref{tab:wild}).
On Bach, AMT, MMT, and REMI all have positive probe margins, and activation patching outperforms the random-subspace control for all target keys.
The same pattern holds across the evaluated AMT model sizes.
On pop, however, probe performance and patching effect do not agree.
AMT has the highest probe margin but the lowest replacement success rate, whereas MMT and REMI do not outperform the note-counting baseline in probing but outperform the random-subspace control for all target keys under activation patching.
Thus, probe performance and patching effect do not necessarily agree in the public models.

Additional analyses show the same separation.
On Bach, replacement shifts the probability distribution over the next pitch toward the target key before any new note is generated, whereas a random subspace of the same dimension produces little change.
In AMT and REMI, patching only pitch positions is largely ineffective, whereas patching structural positions immediately before pitch prediction produces an effect comparable to unrestricted patching.
Across the layers of AMT-12L, the edit margin peaks at layer~$8$, whereas the probe margin peaks at layer~$10$.
Together with Sec.~\ref{sec:h5}, these results show that probe performance alone does not identify where changing key-related information most strongly affects generation.

\subsection{Replacement versus Addition}
\label{sec:addition}
% Addition（steering）は，replacementと異なり，既存の成分$P_Vh$を残す．
% 同じ変位量ではreplacementの方が大きな効果を示す．
% 一方，変位量を2倍にするとadditionはreplacementと同程度以上のsuccess rateに達する．
% したがって，本結果が示すのは，replacementが常に優れることではなく，同じ変位量でより大きな効果を示すことである．
Unlike replacement, addition (steering) retains the existing component $P_{V_\ell}h_\ell(t)$.
At matched displacement, replacement produces a larger effect than addition (Table~\ref{tab:main}).
Doubling the addition displacement allows it to reach a comparable or higher success rate.
Thus, our result does not show that replacement always achieves the highest success rate, but that it produces a larger effect when the activation displacement is matched.

\section{Limitations}
\label{sec:limits}
% 本研究の結論は，本研究で評価したモデルおよび介入手法の範囲に限られる．
% 主な因果解析では正確な調ラベルを得るために合成音楽を用い，実音楽への一般化については公開モデルを用いて評価した．
% 本研究では，評価対象としたモデルが調を置換可能な形式で表現し，その表現が生成に影響することを示したが，すべての音楽Transformerが同じ表現を持つことや，モデルが人間と同じように調を理解していることは主張しない．
% また，likelihoodに基づくsuccess criterionはreference modelによる評価に基づいており，音楽的品質を直接評価するものではない．
% さらに，本研究では聴取実験を行っていない．
% 絶対的なsuccess rateは，データセットによって調推定性能が異なるため，各corpus内で解釈する必要がある．
Our conclusions are limited to the models and interventions evaluated here.
Our main causal analyses use synthetic music to obtain exact key labels, while we assess generalization to real music using publicly available models.
We show that the evaluated models represent key in a replaceable form that affects generation, but we do not claim that all music Transformers use the same representation or that the models understand key in a human-like manner.
Our likelihood-based success criterion relies on a reference model and does not directly measure musical quality.
We also do not conduct a listening test.
Absolute success rates should be interpreted within each corpus because key-estimation performance differs across datasets.

\section{Conclusion}
% 本研究では，調を置換可能な形式で表現し，置換後の値を生成時に利用することを，本研究における「調を知っている」と定義した．
% 線形プロービングによって調情報を読み出し，activation patchingによってその情報を目標調のものに置き換えた．
% 調表現の置換は，新しい音符を生成する前から音高予測を目標調の方向へ変化させ，生成音楽が目標調に従う割合も増加させた．
% 一方，probe性能と介入効果は必ずしも一致しなかった．
% したがって，内部表現から情報を読み出せることと，その情報が実際の生成に利用されていることは区別して評価する必要がある．
We define knowing the key in this study as representing it in a replaceable form and using the replaced value during generation.
We use linear probing to identify key-related information and activation patching to replace it with information for a target key.
Replacing the key representation shifts pitch prediction toward the target key before any new note is generated and increases target-key following in the generated music.
However, probe performance does not reliably predict the effect of patching.
These results show the importance of distinguishing whether information can be read from an internal representation from whether the model actually uses that information during generation.
We release the testbed, code, and demos at \repourl.
